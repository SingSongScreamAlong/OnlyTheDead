## 📜 LICENSE OVERVIEW

This document tracks all sound effect sources, licenses, and required attributions for the Only The Dead project.

### Why This Matters:
- **Legal compliance** - Respect creators' rights
- **Educational integrity** - Proper academic citation
- **Commercial viability** - Clear rights if project is monetized
- **Community respect** - Give credit where due

---

## 🎯 LICENSE TYPES USED

### 1. PUBLIC DOMAIN (PD)
**Rights**: No restrictions, free to use
**Attribution**: Not required (but appreciated)
**Commercial use**: YES
**Modification**: YES
**Redistribution**: YES

**Sources Using This**:
- Historical recordings (100+ years old)
- Some SoundBible content
- Some Freesound content (marked CC0/PD)

---

### 2. CREATIVE COMMONS ZERO (CC0)
**Rights**: Creator waives all rights
**Attribution**: Not required (but appreciated)
**Commercial use**: YES
**Modification**: YES
**Redistribution**: YES

**Sources Using This**:
- Pixabay Sound Effects Library
- Some Freesound content (CC0 marked)

**How to Credit (Optional)**:
```
Sound Name by Creator Name (Source: Pixabay/Freesound)
```

---

### 3. CREATIVE COMMONS ATTRIBUTION (CC-BY 3.0/4.0)
**Rights**: Free to use with attribution
**Attribution**: **REQUIRED**
**Commercial use**: YES
**Modification**: YES
**Redistribution**: YES (with same attribution)

**Sources Using This**:
- Most Freesound.org content
- Some BBC Archive content

**How to Credit (REQUIRED)**:
```
Sound Name by Creator Name
Source: Freesound.org
License: CC-BY 3.0 (or 4.0)
URL: [direct link to sound]
```

**In-Game Credit Format**:
```
[Sound Name] by [Creator] (CC-BY 3.0) - freesound.org
```

---

### 4. BBC REMARC LICENSE
**Rights**: Personal, educational, and research use
**Attribution**: **REQUIRED**
**Commercial use**: **NO** (separate license required)
**Modification**: YES (for permitted uses)
**Redistribution**: NO

**Sources Using This**:
- BBC Sound Effects Archive (33,000+ sounds)

**IMPORTANT FOR OUR PROJECT**:
- ✅ **ALLOWED**: Educational game, historical research, non-profit
- ❌ **NOT ALLOWED**: Commercial sale without separate commercial license
- ✅ **Our status**: Educational/historical = PERMITTED USE

**How to Credit (REQUIRED)**:
```
Sound effects provided by the BBC Sound Effects Archive
Source: sound-effects.bbcrewind.co.uk
License: RemArc (Educational Use)
```

**If We Monetize**:
- Must obtain commercial license from BBC
- Or replace BBC sounds with commercial-licensed alternatives
- Document which sounds need replacement

---

### 5. ROYALTY-FREE (PURCHASED)
**Rights**: One-time purchase, perpetual license
**Attribution**: Not usually required (check specific license)
**Commercial use**: YES
**Modification**: Usually YES
**Redistribution**: Usually NO (as source files)

**Sources Using This**:
- BOOM Library (if purchased)
- A Sound Effect libraries
- Pond5 individual sounds

**How to Credit (Optional)**:
```
Sound Name from [Library Name]
Licensed for commercial use
```

## 📊 TRACKING SPREADSHEET

### Create: `audio_attribution.xlsx` or `.csv`

**Columns**:
1. **Project Filename** - Our filename in game
2. **Original Filename** - Original file from source
3. **Source** - Where it came from
4. **Creator** - Who made it
5. **License** - Specific license type
6. **Attribution Required** - YES/NO
7. **Commercial Use OK** - YES/NO/CONDITIONAL
8. **URL** - Direct link
9. **Download Date** - When acquired
10. **Notes** - Special conditions
11. **Attribution Text** - Exact text to use

**Example Rows**:
```
WPN_RIFLE_LEBEL_FIRE_01.wav | rifle_shot_outdoor.wav | Freesound | Username123 | CC-BY 3.0 | YES | YES | https://... | 2025-11-10 | Modified pitch | "rifle_shot_outdoor by Username123 (CC-BY 3.0)"

ENV_RAIN_HEAVY_01.wav | rain_heavy_loop.wav | BBC Archive | BBC | RemArc | YES | NO* | https://... | 2025-11-10 | *Educational use only | "BBC Sound Effects Archive"
```

## 🔍 LICENSE VERIFICATION PROCESS

### For Each Sound Added:

1. **Check License Page**
   - Read full license terms
   - Note any special conditions
   - Screenshot license page for records

2. **Document Everything**
   - Add to tracking spreadsheet
   - Note attribution requirements
   - Save original file metadata

3. **Test Attribution**
   - Write attribution text
   - Verify it meets license requirements
   - Check URL still works

4. **Regular Audits**
   - Monthly: Review new additions
   - Quarterly: Verify all URLs still active
   - Before release: Complete compliance check

## 🎯 BEST PRACTICES

### Professional Standards:

1. **Over-document** - More info is better
2. **Save evidence** - Screenshot license pages
3. **Regular backups** - Attribution spreadsheet backed up
4. **Clear organization** - Easy to audit
5. **Prominent credits** - Don't hide attributions
6. **Respect creators** - Give credit even when not required
7. **Update regularly** - Keep records current

### Ethical Standards:

1. **Honest use** - Don't misrepresent licenses
2. **Support creators** - Link to their work
3. **Community contribution** - Consider sharing our sounds later
4. **Educational mission** - Remember the educational purpose
5. **Historical respect** - Appropriate use of historical materials
