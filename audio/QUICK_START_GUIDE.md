# QUICK START GUIDE - Audio Asset Acquisition

**Project**: Only The Dead - Battle of Verdun 1916
**Purpose**: Immediate action plan for sound acquisition
**Time to first sounds**: 1 hour
**Time to MVP audio library**: 1-2 weeks

---

## 🚀 START HERE - FIRST HOUR

### Step 1: Set Up Accounts (15 minutes)

1. **Freesound.org** (REQUIRED)
   - Go to: https://freesound.org/home/register/
   - Create free account
   - Verify email
   - **Why**: Largest free sound library, highest priority

2. **Pixabay** (Optional - can download without account)
   - Go to: https://pixabay.com/sound-effects/
   - Can use without account
   - **Why**: Easy downloads, no attribution required

### Step 2: Create Tracking System (10 minutes)

1. **Create attribution spreadsheet**:
   ```
   File: audio_attribution.xlsx (or Google Sheets)
   ```

2. **Columns needed**:
   - Project Filename
   - Original Filename
   - Source
   - Creator
   - License
   - URL
   - Date
   - Attribution Text

3. **Save template** - Fill as you download

### Step 3: First Downloads - Artillery (30 minutes)

**Priority #1: Artillery Whistles**

Go to Freesound, search for:
1. "incoming shell" - Download top 5 results
2. "artillery whistle" - Download top 5 results
3. "rocket whoosh" - Download top 5 results (can be pitched down)
4. "firework mortar" - Download top 5 results (excellent whistles)

**Priority #2: Explosions**

Search for:
1. "explosion outdoor" - Download top 10 results
2. "artillery impact" - Download top 5 results
3. "distant explosion" - Download top 5 results

**Document each download immediately in spreadsheet**

### Step 4: First Environmental Sounds (15 minutes)

**Rain** (essential):
1. Search "heavy rain" - Download 3 long loops (2+ minutes)
2. Search "rain metal" - Download 3 variations (rain on helmet)

**Mud**:
1. Search "mud footsteps" - Download top 10 results
2. Search "mud squelch" - Download top 5 results

### Weekend: Custom Recording (If Needed)

**Equipment needed**:
- Smartphone (minimum) or
- Field recorder (Zoom H5/H6) - $200-300
- Quiet location for recording

**Easy to record**:
1. **Mud sounds**:
   - Find muddy location
   - Record footsteps (walk, run, struggle)
   - Record hand in mud (squelch, pull out)
   - Record mud sliding

2. **Water sounds**:
   - Dripping
   - Splashing
   - Pouring
   - Rain (if raining)

3. **Equipment foley**:
   - Canvas bags
   - Metal equipment
   - Wood objects
   - Fabric rustling

**Recording tips**:
- Record at 48kHz, 24-bit if possible
- Get 5-10 takes of each sound
- Record room tone (background silence)
- Vary intensity
- Close mic for detail

## ✅ DAILY WORKFLOW

### Every Time You Download Sounds:

1. **Search** - Use specific terms
2. **Listen** - Before downloading (preview)
3. **Download** - High quality (WAV > MP3)
4. **Document** - Add to spreadsheet IMMEDIATELY
   - Filename
   - Source
   - Creator
   - License
   - URL
5. **Organize** - Move to appropriate folder
6. **Rename** - Use naming convention
7. **Backup** - Daily backup of downloads

**Time per sound**: 2-3 minutes
**Daily goal**: 20-30 sounds = 1 hour/day

### If Stuck:

**Can't find specific sound**:
