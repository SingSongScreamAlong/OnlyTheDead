# Documentation Hub

This directory consolidates all written material that supports the Only The Dead project.

## Structure

```
docs/
├── verdun_anthology/      # Historical research + reference material
├── development/           # Game design bible + roadmap
└── companion/             # Combined, publication-ready compilations
```

### verdun_anthology/
Historical research foundation. Use this when you need sourced facts, timelines, and references.

Key entry points:
- `README.md` – anthology overview
- `README_ANTHOLOGY_VS_DEVELOPMENT.md` – explains doc split
- `HISTORICAL_ACCURACY_STATEMENT.md` – sourcing methodology
- Subfolders: `timeline/`, `survival/`, `geographic_data/`, `characters/`, `stories/`, etc.

### development/
Game implementation stack. Contains:
- `ONLY_THE_DEAD_DEVELOPMENT_BOOK.md` – design bible (mechanics, missions, narrative)
- `ROADMAP.md` – phase-by-phase tracker (current + upcoming work)

### companion/
Publication-ready exports that merge research + design for sharing.
- `COMPANION_BOOK_COMPLETE.md`
- `COMPANION_BOOK_SUMMARY.txt`

## Contribution Guidelines
1. **Historical facts** → `docs/verdun_anthology/`
2. **Game design & implementation** → `docs/development/`
3. **Combined/curated outputs** → `docs/companion/`

Refer back to the root `README.md` for a full project overview.
