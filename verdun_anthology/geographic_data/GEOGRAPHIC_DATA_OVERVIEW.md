# VERDUN BATTLEFIELD GEOGRAPHIC DATA
## Accurate Coordinates & Terrain Foundation for Game Development

**Purpose**: Provide historically accurate geographic data for terrain generation in UE5, Houdini, or any game engine.

**Coordinate System**: WGS84 (standard GPS coordinates, compatible with all modern tools)

**Elevation Data**: Meters above sea level (m)

**Sources**:
- Historical military maps (1916, French/German)
- Modern IGN (Institut Géographique National) data
- Geoportail aerial surveys
- Academic studies (battlefield archaeology)

## SEASONAL TERRAIN CONSIDERATIONS

### **FEBRUARY-APRIL 1916 (Winter → Spring)**
- **Ground State**: Frozen (Feb) → Thawing (March) → Muddy (April)
- **Vegetation**: Bare trees, no leaves, dead grass
- **Visibility**: Good (no foliage), but smoke/dust from bombardment
- **Water**: Rivers/streams swollen from snowmelt
- **Mud Depth**: 10-30cm (April worst)

### **MAY-AUGUST 1916 (Spring → Summer)**
- **Ground State**: Drying (May-June) → Dry (July-August)
- **Vegetation**: New growth (early), then destroyed by bombardment (mid-battle)
- **Visibility**: Dust clouds from shells
- **Water**: Lower levels, some streams dry
- **Mud Depth**: Minimal (except post-rain)

### **SEPTEMBER-DECEMBER 1916 (Autumn → Winter)**
- **Ground State**: Rain returns (Sept-Oct) → Freezing (Nov-Dec)
- **Vegetation**: None (everything destroyed by 9 months of battle)
- **Visibility**: Rain, mist, early snow (Dec)
- **Water**: Rising again (autumn rain)
- **Mud Depth**: Returns (Oct-Nov), then freezes (Dec)
